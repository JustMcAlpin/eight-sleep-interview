## The Temperature Card

There are 3 temperature phases in one night's sleep session: Bedtime, Night, and Morning

The temperature card shows the user's preset temperatures for each phase at the top of the card, with the current phase's temperature shown in the center of the card.  

## UX: 
Pressing the +/- buttons will adjust the currently selected phase temperature.
The temperature setting has 4 states: On, idle, cooling, warming.  
The temperature values range from -10 to +10, including 0, which represents a neutral state (not off)
Tapping the "OFF" turns the temperature on, and tapping the current temperature value shows a bottomsheet that asks for confirmation to turn off temp.
